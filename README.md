                                 Amazon-Style E-commerce Application
  
console-based Amazon-style E-commerce application developed using Java and the Collections Framework.

This application demonstrates core Java concepts and object-oriented programming principles while implementing basic e-commerce operations.

 Technologies Used in this project

- Java
- Core Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Exception Handling

Features

- View available products.
- Add products to the shopping cart.
- Remove products from the cart.
- Update product quantities.
- Calculate total cart price.
- Place orders.
- Manage customer details.
- and many other.....
